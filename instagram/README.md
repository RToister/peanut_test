# Instagram: сайти та Telegram-боти

Готові картинки лежать у `out/`. Їх можна одразу завантажувати в Instagram.

| Файл | Що це | Розмір |
|---|---|---|
| `profile-avatar.png` | Аватар профілю `<R/>` (обраний) | 1080×1080 |
| `profile-avatar-1…8.png` | Запасні аватари без літер | 1080×1080 |
| `facebook-cover.png` | Обкладинка Facebook-сторінки | 1640×924 |
| `01-…10-*.png` | Перші 10 постів | 1080×1350 (4:5) |
| `highlight-*.png` | Обкладинки для «Актуального» | 1080×1920 |
| `story-template.png` | Сторіс «Нова робота» | 1080×1920 |

## Як оновити картинки

```bash
node instagram/src/shoot.js    # перезняти скріншоти демо-сайтів (якщо їх змінювали)
node instagram/src/render.js   # перезібрати всі картинки в instagram/out/
```

Усі тексти, кольори, нікнейм (`HANDLE`) і підпис у футері (`TAGLINE`) задаються в `src/render.js`.

## Ідеї для наступних постів

- **До/після**: сторінка клієнта в конструкторі й новий сайт
- **Telegram-бот у дії**: запис екрана, як клієнт записується через бота (Reels)
- **«3 помилки на сайтах салонів»**: карусель за форматом 03
- **Відгук клієнта**: скріншот повідомлення + фото сайту
- **Reels**: прокрутка готового сайту на телефоні під трендовий звук (найкраще працює на охоплення)
